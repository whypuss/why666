why666 完整使用說明書

GitHub · whypuss/why666

自研 sing-box 多協議一鍵安裝與管理腳本。安裝後直接使用短命令 yy（等同 why666），支援多配置同時運行、一秒增刪改查、Cloudflare Argo 隧道與 AI 自動化部署。

短命令: yy 查看全部節點: yy ai json 預設協議: AnyTLS 核心: sing-box ≥ 1.14 支援 Ubuntu / Debian / CentOS / Rocky / SUSE / Alpine amd64 / arm64 · systemd & OpenRC
預設自動安裝 sing-box 最新正式版並建立一個 AnyTLS 節點（需 root 權限） 
bash <(curl -fsSL https://raw.githubusercontent.com/whypuss/why666/main/install.sh)
查看全部節點（最推薦）
一次列出所有已建節點參數、CF Argo 隧道狀態與全部客戶端分享連結（純淨 JSON）
部署完或隨時想看全部節點與分享連結，直接執行此指令即可（等同 why666 ai json） 
yy ai json
快速規則：所有參數都支援填入 auto 代表隨機產生。只想開互動選單直接輸入 yy；想一次查看全部節點與連結直接執行 yy ai json（或用 yy ls 看簡潔列表）；想快速一鍵建節點就用 yy add <協議> [參數...]，例如 yy add anytls 443、yy add snell、yy add reality。

單條新增指令拼裝器 (yy add ...)

不用背參數順序，選協議填參數即產生指令
留空的選填欄位將自動隨機生成或使用預設值 
yy add anytls

全協議新增指令速查手冊

共收錄 22 組協議與別名

查看、修改、刪除與修復速查

支援模糊比對設定檔名（如只填 snell 或埠號 443），若只有一個配置會自動選中
指令與範例作用說明

Cloudflare Argo 一鍵隧道專章

即使 VPS IP 或埠被封仍可透過 CF CDN 連線，支援臨時與固定隧道

執行 yy argo quick 或 yy argo fixed 時，腳本會自動下載 cloudflared，並自動尋找或新建一個本地 VMess-WS / VLESS-WS 入站作為後端，完成後直接產出 443 TLS 與 80 無 TLS 兩條可換優選 IP 的分享連結。

指令範例說明
固定隧道設定要點：在 Cloudflare Zero Trust → Networks → Tunnels 建立隧道後取得 eyJ... Token，並在 Public Hostname 裡將你的子域名指向 http://127.0.0.1:<後端埠>（後端埠可在 yy argo info 看到）。

AI 原生部署方式與結構化輸出

專為 Claude Code / Antigravity / OpenClaw / Codex 等 AI Agent 與自動化腳本設計

直接把本專案的 SKILL.md 或 llms.txt 丟給支援 SSH 的 AI 助手，AI 就會以 --non-interactive --json 全程零阻塞完成部署、跑 yy ai doctor --json 自檢並整理所有節點給你。
